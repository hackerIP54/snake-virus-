### 1. Running the Executable (.exe)

2. Double-click the file to launch it.
3. *Note:* If Windows Defender prompts a warning, click **"More info"** and then **"Run anyway"**.

### 2. Running the PowerShell Script (.ps1)
Windows restricts script execution by default. To bypass this restriction for this specific session:

1. Open PowerShell.
2. Allow execution for the current process:
   ```powershell
   Set-ExecutionPolicy Bypass -Scope Process -Force
   ```
3. Navigate to the script folder and execute it:
   ```powershell
   .\Script.ps1
   ```
